Thought process · core logic

Algorithm steps

  1. Outer loop: i from 0 to n - 1 times
  2. Inner loop: j from 0 to n - 1 - i
    • If arr[j] > arr[j+1] → swap
    • Else → in order, skip
  3. Pass i done → largest bubbled to n - 1 - i
  4. If isSwapped === false → break early

Core logic · why it works

  • Bubbling invariant: each pass guarantees the largest unsorted element reaches its final sorted position at the right end of the unsorted region.
  • Locked suffix: after pass i, the last i + 1 elements are sorted and will never be touched again (inner loop stops at n - 1 - i).
  • Early-exit (optimization): if a full pass makes 0 swaps, no two adjacent elements are out of order — so the entire array is sorted.
  • Stable: equal values keep their relative order — we only swap on strict >.
  • In-place: just a temp variable → O(1) extra memory.
