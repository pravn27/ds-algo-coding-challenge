Bubble Sort — Ascending Order

Nested loops: outer pass i · inner compare j vs j+1 · swap if out of order — matches index.js

Mnemonic: Each pass bubbles the largest unsorted element to its final position at the right. Compare adjacent arr[j] vs arr[j+1]: if out of order, swap. After pass i, the last i+1 elements are sorted. If a full pass makes 0 swaps → already sorted → early exit.
